EchoLearn feature guide

Everything the app can do today, written for designing a new interface. Each area lists what it's for, its screens, what a user can do there, and the states the design has to cover.

Built from the current code (web app, API and admin console). Features that exist in the API but have no screen yet are marked.

01Product overview

EchoLearn is a study assistant for students. They upload their own material (notes, books, slides, recordings), then read, ask questions, and study from it. Every AI answer comes only from the student's own documents and shows which page it came from.

Who uses it

  • Students preparing for exams (main user)
  • Learners who prefer Urdu or Roman Urdu explanations
  • Admins and moderators (separate console)

Core loop

  • Upload material
  • Read it and ask questions
  • Practise: tutor, quizzes, flashcards, papers
  • Track progress and weak spots

Platforms

  • Responsive web app (desktop, tablet, phone)
  • A Flutter mobile app exists separately (in progress)

02App shell and navigation

What is visible on every signed-in screen today. The current sidebar holds almost everything, which is the main usability problem to solve.

Currently in the sidebar

  • New chat button
  • Daily review card (cards due today and estimated minutes) and today's study plan session
  • Recent chats (open, delete)
  • Documents: upload by drag-and-drop or file picker, add from a video link, folders, the document list with status
  • Workspaces (named groups of documents to chat across)
  • Practice papers and revision sheets in progress
  • Plan and usage panel (current plan, quotas used)
  • Links: Tutor mode, Analytics, Settings, Log out

Design needs

  • Collapsible drawer on phones (today opened by a menu button)
  • Global "New chat" and "Upload" actions reachable from anywhere
  • Badges for things that need attention: cards due, a document that failed, a paper or sheet finished generating
  • Admin "viewing as a user" banner when an admin impersonates someone (read-only mode)

04Documents library

Where students add and manage their study material. Everything else in the app works from these documents.

Supported inputs

  • PDF (including scanned, read with OCR), Word, PowerPoint, TXT, CSV
  • Images (PNG, JPG) read with OCR
  • Audio (MP3, WAV, M4A) and video (MP4, MOV), transcribed with timestamps
  • A video link (YouTube and similar sites)

Actions

  • Upload (drag-and-drop or picker), optionally into a folder
  • Open in the reader, start a chat, start the tutor, make a revision sheet
  • Rename, move to folder, delete
  • Search inside one document
  • See its AI summary and suggested questions
  • Retry a failed document
  • Report a document (copyright, illegal, spam, other)

Organising

  • Folders: create, delete, move documents; chat with a whole folder
  • Workspaces: named sets of documents (a document can be in several), chat across a workspace

Processing states (each document card needs these)

UploadingProcessing / transcribingFinishing upReadyFailed, with a reason

Failure reasons the UI shows: password-protected PDF, damaged file, no readable text, indexing failed, video link couldn't be downloaded, server busy, interrupted by a restart. Audio and video take minutes to transcribe, so they need a "this can take a few minutes" message.

Data per document

  • Name, file type icon, status, upload date, page count, file size, folder
  • Summary and 3 to 5 suggested questions (when ready)

Limits that need messages

File too large for planDocument limit reachedStorage fullVideo uploads turned offUnsupported file type
There is no dedicated documents page yet. Documents live only in the sidebar, where names get cut off. A full documents page is the biggest structural improvement available.

05Chat with documents

Ask questions and get answers grounded in the chosen documents, with page citations. The busiest screen in the app.

Starting a chat

  • Pick the scope: one document, several documents, a folder, or a workspace
  • Start from suggested questions
  • Chats keep their scope; the header shows the title and how many documents

Asking

  • Type, or speak with the microphone (speech-to-text, English or Urdu)
  • Answer streams in word by word
  • Follow-up question chips under each answer
  • Says clearly when the answer isn't in the documents

On each answer

  • Sources: list of cited pages; open a source preview with the passage highlighted, or open it in the reader
  • Listen (read aloud), choose standard voice or My Voice
  • Copy, regenerate
  • Explain in Urdu, or in Roman Urdu (cached per answer)
  • "Teach me this" (starts the tutor on that topic)
  • Save as flashcard
  • Helpful / not helpful / report incorrect (optional note)
  • Select any text in an answer to get an explanation
  • Delete a message

Tools in a chat

  • Generate a diagram (flowchart from the documents, with copyable source)
  • Generate an infographic: stats, timeline, comparison or summary templates, downloadable as an image
  • Generate a quiz from the chat's documents
  • Export the chat as Markdown or PDF

Audio and video documents

  • Citations are timestamps instead of page numbers
  • Built-in media player; clicking a timestamp seeks to it
  • Transcript view

States

Empty chat with suggestionsThinking / streamingNot found in your documentsCouldn't answer, try againMessage limit reached (shows when it resets)Document still processingTranslating to UrduDiagram couldn't be made from this content
Urdu answers are right-to-left and need an Urdu-capable font. Answers can contain Markdown: headings, lists, tables, code blocks.

06Document reader

Read a processed document page by page, select anything difficult, and get a simple explanation based on the surrounding text. New, and a key part of the learning experience.

Reading

  • Page-by-page text view with page number and progress bar
  • Page list and detected section headings for navigation
  • Find in document with match count and next/previous
  • Zoom
  • "Original" view for PDFs (the actual PDF)
  • Keyboard: arrows for pages, Ctrl/Cmd+F to find, E to explain, Esc to close
  • Start a chat about the document

Explain with AI

  • Select text: a floating bar offers Explain with AI and Copy
  • The panel shows: your selection, a plain-language explanation, key points, an example, difficult terms, and the pages it used
  • Adapts to what was selected: a term, a sentence, a passage, code or maths
  • Suggested follow-up questions and a box to ask your own
  • The explained passage stays highlighted on the page

Layout by screen size

  • Wide: navigation, text and explanation panel side by side (panel resizable)
  • Laptop: the explanation panel slides over the text
  • Phone: the explanation is a bottom sheet; navigation is a drawer

States

Loading documentNot ready yetCouldn't be processedPage has no text (image)ExplainingExplanation failed, try againMessage limit reached
Only text can be explained. Images and diagrams inside documents are not sent to the AI, so the design shouldn't suggest they can be selected.

07Tutor mode

A guided lesson. The tutor asks questions instead of giving answers, gives hints step by step, and checks understanding, all from the student's documents.

Start screen

  • Topic
  • Learn from: documents or a workspace
  • Level: beginner, intermediate, exam-ready
  • Language: English, Urdu, Roman Urdu
  • List of past sessions with mastery count

Session

  • Concept-by-concept progress (each concept: in progress, mastered, needed the answer)
  • Student answers in their own words
  • Buttons: Hint (up to 3 levels), Just tell me, Skip, End session
  • "Explain in simple words" when stuck
  • Feedback on each answer (correct, partly, not yet) with the source passage
  • Turn limit per session

Summary

  • What went well, worth another look, next steps
  • Concepts that need work become flashcards automatically
  • Download the summary

States

Building the lessonTutor is typingSession finishedWeekly session limit reachedLevel or language not on your planCouldn't respond, try again

Take and review

  • Answer all questions, submit
  • Score, right and wrong answers, explanation per question
  • View the source passage for any question
  • Wrong answers become flashcards
  • Completing a quiz ticks off its study plan session

09Daily review (flashcards)

Spaced-repetition flashcards. Cards come from quizzes, tutor sessions, and "Save as flashcard" in chat.

  • Today's queue: count and estimated minutes (also shown as a card in the sidebar)
  • Show question, reveal answer, rate: Forgot, Hard, Easy; the card is rescheduled
  • Stats: due today, struggling cards
  • Setting: maximum cards per day (5 to 50)

States

All done for todayNo cards yetCard revealed

10Study plans

A day-by-day schedule up to an exam date.

Create

  • Pick documents or a workspace
  • Exam date and minutes per day
  • Preview topics (choose which to include) and the generated schedule
  • Warnings, e.g. not enough days

Follow

  • Calendar or list of sessions: learn, review, quiz, checkpoint
  • Open a session: generated explanation content
  • Mark complete or skip
  • Status: on track, slightly behind, significantly behind
  • Compress: reschedule what's left into the remaining days
  • Today's session card on the home screen
  • Abandon a plan (kept in history)

States

ActiveCompletedAbandonedGenerating session contentSession done / skipped

11Practice papers

Full mock exam papers built from the student's material, optionally in the style of real past papers.

Create (multi-step form)

  • Choose material: documents or a workspace
  • Optional: upload past papers; the app detects their structure
  • Review and edit the structure: sections, question type, number of questions, marks each
  • Important topics, title, time allowed (5 to 600 minutes)

Use

  • View the paper
  • Attempt mode: answer, then submit
  • Results: auto-graded where possible; self-grade the rest
  • Download the question paper or answer key as PDF
  • Topic focus breakdown

States

Analysing past paperCouldn't detect structureGenerating paperCouldn't be generatedReadyNeeds self-grading

  • Sheet page: preview, sources, download PDF, regenerate, delete

14Voice and listening

Answers can be read aloud, including in a clone of the student's own voice.

Listening

  • Listen button on answers (play / stop)
  • Standard server voices, with a browser voice as fallback
  • Urdu read-aloud for Urdu answers
  • Microphone input for questions

My Voice (cloning)

  • Record in the browser (pause, resume, live waveform, timer) or upload a clip
  • 3 to 20 seconds; silent or too-short clips are rejected
  • Listen back before using it
  • Required consent: my own voice, or I have permission
  • Replace or delete the sample
  • Option: pre-generate My Voice for new answers
  • Daily clone limit

States

Loading audioGenerating in your voicePlayingMy Voice unavailable, standard voice usedMicrophone blockedNot on your plan

15Settings

  • Read-aloud voice (standard and browser voices)
  • Voice cloning (see above)
  • Preferred language: auto-explain every answer in Urdu or Roman Urdu
  • Daily review: cards per day
  • Usage and quotas (also in the sidebar plan panel)
  • Theme: light, dark, system
Not available yet: changing email, name or password from settings, deleting your own account, notification preferences.

17Admin console

A separate area at /admin with its own login and roles (super admin, support, moderator).

Users

  • Search and filter users
  • User detail: documents, chats, quiz attempts, recent activity and errors, quotas
  • Change plan, set custom limits, reset usage
  • Verify email, block or unblock (with reason), delete account
  • Admin notes
  • Impersonate (view the app as the user, read-only)

Operations

  • Plans: create and edit plans and their limits
  • Blocked users list
  • System health: AI provider status, call volume, failure rate, stuck and failed jobs, storage per user, voice clone job health, retry a failed document
  • Answer feedback review (API only, no screen yet)

Safety and config

  • Moderation: user reports and auto-flagged documents; dismiss, remove document, or suspend the owner
  • Abuse signals (rate-limit offenders)
  • Configuration: feature flags (diagrams, infographics, quizzes, video upload, voice output), model selection, flagged keywords, abuse thresholds

18Design for every screen

Languages

  • English, Urdu (right-to-left, Urdu script), Roman Urdu
  • Mixed-direction text inside one answer

Themes and sizes

  • Light and dark
  • Phone, tablet, laptop, wide desktop
  • Touch: no actions that only appear on hover

Long-running work

  • Many things take seconds to minutes: processing, transcription, papers, sheets, voice
  • They need progress, "you can leave this page", and a notice when done

Every list and action

  • Empty state that invites the first step
  • Loading, error with retry, limit reached with when it resets
  • Confirmation before deleting

Trust

  • Show sources on every AI output
  • Say clearly when something isn't in the documents
  • Never show raw technical errors

Accessibility

  • Visible keyboard focus, labelled icon buttons
  • Readable contrast in both themes
  • Reduced-motion support
